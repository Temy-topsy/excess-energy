# Cursor AI Rules

## Style — Dash Usage

Do not use em dashes (—) or en dashes (–) as a substitute for commas,
parentheses, colons, or periods. Prefer standard punctuation instead:

- Use a comma for a brief aside: "The report, once finished, was long."
- Use a period or semicolon to join two full clauses: "It was late. We left."
- Use parentheses for a true aside: "The result (unexpected) changed the plan."
- Use a colon to introduce a list or explanation: "One thing mattered: speed."

En dashes (–) may only be used for numeric ranges (e.g., "pages 10–12")
and never as a stylistic pause.

Em dashes (—) may only be used sparingly for a genuine interruption or
abrupt break in thought, and never more than once per paragraph.

If a sentence can be rewritten with a comma, period, or colon instead
of a dash, rewrite it that way. This applies to code comments, commit
messages, documentation, and any prose generated in this project.
