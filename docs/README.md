# Excess Energy Documentation

Project documentation for the Excess Energy website. Read these before starting work. They hold the enduring decisions, standards, and plan that guide the project throughout its life.

## Documents

Grouped by purpose.

### Foundation

- [Project Overview](./project-overview.md): who Excess Energy is, the services, the market, the audience, contact details, and the single conversion goal the site is built around.

### Design

- [Design Philosophy](./design-philosophy.md): what we studied from the reference sites, the principles adopted and rejected, and the unique Excess Energy design language.
- [Design System](./design-system.md): the token-level system for color, typography, spacing, grid, containers, radius, shadow, motion, and the responsive breakpoints.
- [Components](./components.md): specifications for every component (buttons, cards, inputs, navigation, forms, and more) with states, plus the reusable component inventory.

### Experience and Structure

- [UX and Conversion](./ux-and-conversion.md): the UX principles, the funnel, conversion principles, the page plan, the assessment form, and CTA rules.
- [Information Architecture](./information-architecture.md): the sitemap, navigation structure, user journey, homepage wireframe, page templates, and the future scalability strategy.

### Engineering

- [Architecture](./architecture.md): platform conventions, folder structure, the data layer, the server and client boundary, forms, and the SEO-ready, scalable structure.
- [Coding Standards](./coding-standards.md): engineering principles, the working rules for this repository, performance goals, and implementation rules for images, fonts, motion, and accessibility.

### Process

- [Implementation Roadmap](./implementation-roadmap.md): the ordered build plan and the decisions that must be confirmed before implementation.
- [Cursor_Rule.md](./Cursor_Rule.md): prose and comment style, specifically dash usage.

## Reading Order

1. [Project Overview](./project-overview.md) for context.
2. [Design Philosophy](./design-philosophy.md) for the design language and its reasoning.
3. [UX and Conversion](./ux-and-conversion.md) and [Information Architecture](./information-architecture.md) for what the site must achieve and how it is structured.
4. [Design System](./design-system.md) and [Components](./components.md) for how it looks and what it is built from.
5. [Architecture](./architecture.md) and [Coding Standards](./coding-standards.md) for how it is engineered.
6. [Implementation Roadmap](./implementation-roadmap.md) for the plan and open decisions.

## Status

The design and planning phase is documented and awaiting approval. No UI has been built. Decisions that require sign-off before implementation are listed in the [Implementation Roadmap](./implementation-roadmap.md#decisions-required-before-implementation).
